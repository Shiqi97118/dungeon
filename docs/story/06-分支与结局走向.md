# 06｜分支与结局走向

> 结局不提前写死。本文件给出 20 个“发展方向”——每个只是一种大致的走向，到了终局，由程序按玩家实际的进展挑出候选，再由 AI 写成最让人信服的结局。AI 也可以在证据充分时提出第 21 个方向。

## 1. 原则

1. **方向不是结局**：方向是“世界朝哪边倾斜”，结局是“这支队伍在这次倾斜中留下了什么”。同一个方向，不同的队伍会写出完全不同的结局。
2. **一切都留下痕迹**：玩家的每个重要行动都给某些方向加分或减分，加减分写入存档。
3. **不按好坏排名**：每个方向都有光明的一面和代价。不存在“真结局”。
4. **可以交织**：最终结局可以是一个主方向加一个副方向（如“诸族盟约”加“万名安息”）。
5. **可以生长**：AI 可以在终局提出新的方向，但必须引用存档中至少 3 条证据。

## 2. 倾向分（规则）

- 每个方向一个倾向分，初始 0，不设上限。
- 加分：小事件 +1，重大事件 +2，关键转折 +3。减分同理。每个方向一轮内最多 ±3。
- 加分来源：`03` 的冒险结果、`04` 的势力动向和关系变化、`05` 的人物转折与暗线揭开、以及 AI 判断的自由行动（AI 判断时必须写出一句理由）。
- 倾向分对玩家不可见，但 AI 在叙述中要让玩家感受到世界在倾斜（见各方向的“信号”）。

## 3. 终局的挑选逻辑

1. **确定可用方向**：按 `02` 第 7 节，根据有效选择数（按席位）、已完成核心冒险、真相层级、是否到达空名之城，确定哪些档可用；再做**事实过滤**：各方向的“前提”是硬前提，不成立就不可用；“否定”列出的事实一旦已经发生，该方向也不可用（见第 4 节）。过滤只看存档里已经提交的事实，不看倾向分。D01 始终可用。
2. **排除强烈反向**：倾向分 ≤ −3 的方向不进入候选；若排除后没有方向剩下，只保留 D01。
3. **确定候选数**：候选数 k = min(3, 剩余方向数)。
4. **加权随机**：程序以 max(倾向分, 0) + 1 为权重，不放回地抽出 k 个候选；倾向分 ≥ 3 的方向先入选，不足 k 个时再从其余方向中抽。权重至少为 1，因此负分方向（−1、−2）仍有被抽中的可能，但不会出现零或负的权重。随机种子取存档中的 `seed`，同一存档重放得到相同候选。
5. **只有 1 个候选时**：跳过 AI 裁决中的“选择”，AI 只写理由与结局。
6. **AI 裁决**：AI 读取候选、存档中的故事线、人物印象和最后一轮的选择，选出一个主方向（可加一个副方向），或提出新方向（需 3 条证据）。AI 必须写出“为什么是这个”——引用至少 3 件玩家做过的事。
7. **写结局**：按第 6 节的结构生成。

## 4. 二十个发展方向

### 第 0 档（最短路线可达，2 个，占 10%）

**D01 未竟之歌**
- 一句话：队伍在第七声响起之前离开了舞台，世界自己走了下去。
- 信号：队伍反复拒绝卷入、只做自己的事、在危机中撤退。
- 结局画面：多年后，一个吟游诗人唱起第六声之后的那个夏天，歌里有这支队伍的名字，但没有结尾。
- 代价：没有人知道第七声后来怎样了。
- 可交织：任何方向（作为副方向时，表示“我们只走到了这里”）。

**D02 大遗忘重演**
- 前提（必须是世界灾难事实，至少满足一项，否则 D02 不可用）：大势时钟到达 12 并已发生世界危机（`02` R3）；空名者饥饿 ≥ 8。马库斯掌权、核心冒险失败或撤退只是加分信号，不能单独让 D02 成为候选；选择少、进度低也不会自动导向 D02。
- 一句话：第七声以最糟的方式响起，大陆再一次失去名字。
- 信号：时钟走满而无人干预；马库斯掌权；空名者饥饿 ≥ 8；队伍在关键时刻失败。
- 结局画面：清晨，所有人醒来，不知道自己是谁；队伍中只有一个人还记得同伴的名字。
- 代价：一切。也是新的开始——就像余烬百年那样。
- 可交织：D12（皇帝在大遗忘中归来）、D20（队伍成为新的守钟人，重新给世界命名）。

### 第 1 档（8 个）

**D03 商会之网**
- 一句话：铜脉商会垄断了回响通讯，大陆被金钱连成一张网。
- 信号：钟心交给商会；私井未被揭露；柯德里克态度 ≥ +2；商会接管灰港议会。
- 结局画面：每座城市都有商会的传声亭，人们按字数付钱和远方的亲人说话；低潮街的穷人们仍在“免费治疗”。
- 代价：记忆成为商品。
- 冲突：D07、D09、D14。可交织：D08（学院为商会服务）。

**D04 王冠之钟**
- 一句话：王室掌控了冠钟城，以“永不遗忘”之名统一诸国。
- 信号：冠钟城计划完成；艾瑟琳态度 ≥ +2；烬原被压制；守钟人臣服于王室。
- 结局画面：王都的大钟每日敲响，所有子民的名字都被记录在冠钟城中；艾瑟琳再也不会忘记——她也再也不能。
- 代价：自由；以及冠钟城下那个“温和的古代声音”是否真的离开了。
- 冲突：D06、D07。可交织：D12（若阿斯特里昂未被识破）、D05。

**D05 再封印**
- 一句话：守钟人完成了第二次封印，第七声沉睡，代价是一座城市的名字。
- 信号：帮守钟人修复结界；暗线三未公开或被接受；赛勒斯态度 ≥ +2；队伍提供静音晶体。
- 结局画面：栖钟城（或另一座被选中的城市）的居民们安静地生活，不知道自己曾经叫什么；世界获得了又一个四百年。
- 代价：一座城市，和下一代人要面对的同一个问题。温和版本中，队伍找到了用自愿者代替城市的办法。
- 冲突：D07、D15、D16。可交织：D20（队伍成为新封印的一部分）。

**D06 烬原清算**
- 一句话：烬原收回了圣地，帝国的罪行被清算——通过战争或和约。
- 信号：乌鲁格态度 ≥ +2；真相第三层公开；烬钟城归还；王国与烬原开战或签约。
- 结局画面（战争版）：冠钟城的城墙上插着赤牙的旗帜；（和约版）王都大教堂里，摄政公主跪着念出一千个兽人的名字。
- 代价：战争版是血；和约版是王国的骄傲。
- 冲突：D04。可交织：D11、D19。

**D07 拾名人起义**
- 一句话：被抹去的人被记起，旧秩序在愤怒中崩塌。
- 信号：阿佳莎态度 ≥ +2；暗线一、三公开；名单贴遍各城；激进派行动成功。
- 结局画面：每座城市的广场上都立着一块写满名字的石碑；守钟人和商会的门被砸开。
- 代价：报复也会抹去人——这一次是用火。
- 冲突：D03、D05、D04。可交织：D16、D19。

**D08 学院之火**
- 一句话：星图学院破解了回响之网，知识点燃了新时代，也烧到了人。
- 信号：交给学院钟心或档案；奥兰多态度 ≥ +2；人造钟心成功；实验公开。
- 结局画面：学院塔尖上亮起人造钟心的光，遗忘病有了第一种疗法；卡珊卓的名字写在实验记录的第一页。
- 代价：取决于卡珊卓是否自愿，以及“古代学者”是否被识破。
- 冲突：D13。可交织：D03、D14。

**D09 雾海自由港**
- 一句话：沉默海成为不受任何王国管辖的自由海，回响物品在这里自由流通。
- 信号：莉丝态度 ≥ +2；商会海上势力被击败；雾钟城钟心留在哑歌号。
- 结局画面：锚链湾的灯火通宵不灭，被通缉的人、被遗忘的人、被追猎的人都在这里重新取名。
- 代价：自由也意味着没有人保护你。
- 冲突：D03、D04。可交织：D07。

**D10 银叶归隐**
- 一句话：精灵断开与网络的联系，带着古老的记忆退出了人世。
- 信号：薇娅瑟态度 ≤ 0 或长老会分裂；叶钟城钟心沉寂；林海边境永久关闭。
- 结局画面：银叶林海在一夜之间被雾吞没，只剩树叶还在重复人们最后对精灵说的话。
- 代价：大陆失去最长的记忆。
- 冲突：D11。可交织：D05、D13。

### 第 2 档（6 个）

**D11 诸族盟约**
- 一句话：各势力共同签订盟约，回响之网由诸族共管。
- 前提：至少 3 个势力两两关系 ≥ +2。
- 信号：队伍牵线多方会面；阿斯特里昂被识破；艾瑟琳和乌鲁格都愿意坐下来。
- 结局画面：在空名之城边缘的一张圆桌上，八个势力的代表签下盟约；第七声被定为“只有所有人同意时才能敲响”。
- 代价：盟约脆弱，需要每一代人重新维护。
- 可交织：D06（和约版）、D14、D19。

**D12 皇帝归来**
- 一句话：阿斯特里昂借宿主复生，织音帝国在新的身体里归来。
- 前提：阿斯特里昂未被识破，或被识破后仍有人与他交易。
- 否定：阿斯特里昂已被封印、撕碎或从合唱中永久分离。
- 信号：空名者饥饿 ≥ 5；卡珊卓或某角色被选为宿主；艾瑟琳或乌鲁格接受了他的许诺。
- 结局画面：新皇帝第一次开口时，所有钟同时响了七下；他记得每一个人的名字。
- 代价：大陆的未来交给一个四百年前的人。它可能是和平的，因为他真的不再害怕死亡。
- 可交织：D02、D04。

**D13 毁网**
- 一句话：回响之网被彻底摧毁，所有的回声都沉默了。
- 前提：至少毁掉 2 个节点或钟心。
- 信号：毁掉钟心或回声井；薇娅瑟的代价被知晓并被接受；空名者态度 ≤ −2。
- 结局画面：遗忘病停止了蔓延；精灵们失去了一切古老的记忆，像孩子一样重新学习星象；空名者的最后一句话是“谢谢”或“不要”。
- 代价：被吞的记忆永远不会回来；精灵的古忆消失。
- 冲突：D08、D14、D15。可交织：D10、D19。

**D14 修复之网**
- 一句话：回响之网被修复为公共记忆库；被吞的记忆不能原样找回，但可以借别人保存的回声“重构”出一部分。
- 前提：博林的矮人契约或学院的修复方案被使用。
- 否定：D13 的毁网已经发生（网已不在，无从修复）。
- 信号：私井被关闭；学院、矮人、商会异见派合作；空名者被说服。
- 结局画面：乔安从邻居们保存的回声里，一点一点重新学会了自己的姓——她能念出来，却想不起小时候被人这样叫时的感觉；回声井成为公共的“记忆泉”，任何人都可以去听已故亲人的一句话。
- 代价：重构出来的记忆是拼起来的，缺口永远在；每次重构都要有人交出一段自己保存的回声。网依然存在，诱惑也依然存在。
- 可交织：D11、D08、D15。

**D15 空名者获名**
- 一句话：队伍说出了空名者的名字，它成为一个真正存在的新生命。
- 前提：阿斯特里昂已从合唱中分离或被压制。
- 信号：空名者态度 ≥ +2；妮娜或卡珊卓成为翻译；队伍拒绝封印它。
- 结局画面：一个新的存在第一次用自己的声音说话——那声音不属于任何一个被吞的人，又属于所有人。
- 代价：世界上多了一位无法预测的神。
- 可交织：D14、D19、D17。

**D16 真相之日**
- 一句话：断钟之夜与四百年来所有的掩盖被公开，各势力必须为过去负责。
- 前提：真相层级 ≥ 3，且暗线三、五中至少一条揭开。
- 信号：罗兰的档案原件被公开；薇娅瑟或赛勒斯当众承认；国王在朝堂上说出真相。
- 结局画面：大陆上第一次出现一部所有人都承认的历史书，第一页写着：“我们曾经忘记。”
- 代价：真相打碎了很多人赖以生活的谎言。
- 可交织：D06、D07、D11。

### 第 3 档（4 个，需到达空名之城）

**D17 第七声：重命名世界**
- 前提：队伍在第七道门前；队伍当前持有 ≥ 4 枚钟心（已毁的或在别人手里的不算）；真相第五层已确认。
- 一句话：队伍打开了第七道门，第七声响起，世界的根本规则被重新命名。
- 信号：持有 ≥ 4 枚钟心；真相第五层确认；队伍在门前达成一致。
- 结局画面：第七声响起的那一刻，每个人都听见了自己真正的名字；队伍决定了这个世界从此“万物如何被记住”。
- 代价：队伍为世界取的新名字，就是他们要承担的责任。AI 依队伍的选择具体写出新规则。
- 可交织：D11、D15、D19。

**D18 初鸣者的回答**
- 前提：队伍在第七道门前；真相第五层已确认。
- 一句话：门后是初鸣者离去的“世界之外”，他们回答了。
- 信号：真相第五层确认；薇娅瑟或格里姆船长给出的残卷线索被追到底；队伍中有人愿意“走出去”。
- 结局画面：门后不是宝库，而是一片没有名字的星空；一个声音说：“你们终于学会了自己取名。”若有角色的玩家自愿，他可以留在门后。
- 代价：走进门后的人不会回来；无人自愿时，门在回答之后重新合上。
- 可交织：D17、D20。

**D19 万名安息**
- 前提：队伍到过名字的广场；“安名”（`04` 第 7 节）累计 ≥ 5 次。
- 一句话：所有被吞的记忆被逐一说出名字，然后安息。
- 信号：在名字的广场上说出至少 5 个具体的名字；阿佳莎、薇娅瑟、妮娜中至少两人参与；安息的合唱占上风。
- 结局画面：广场上的空名者一个接一个地微笑、消失；最后一个名字需要有人以自己的名字交换。
- 代价：若有角色的玩家自愿，由他交出自己的名字；若无人自愿，由态度 ≥ +2 的阿佳莎、薇娅瑟或妮娜之一代为交换，或者最后一批名字未能安息、留作下一章的种子。
- 可交织：D11、D13、D15、D07。

**D20 新守钟人**
- 前提：伊芙琳、赛勒斯或其继任者中，至少一人仍在世并把职责托付给了队伍。
- 一句话：队伍成为第七声新的守护者，世界由他们来守。
- 信号：伊芙琳或赛勒斯将职责托付给队伍；守钟人墓中的名字被读完；队伍选择留下。
- 结局画面：多年后，有人在雾墙边见到一群守钟人，他们的钟会响，他们会说出每个来访者的名字。
- 代价：守钟人不能离开，也不能被世界记得。
- 可交织：D05（温和版）、D18、D02。

## 5. 新方向规则

- AI 在终局可以提出不在列表中的方向，命名为“D21 …”。
- 必须同时满足：（1）引用存档中至少 3 条证据（故事线、人物印象或暗线揭开记录）；（2）与已知的世界法则不冲突（见 `01` 第 4 节）；（3）该方向的“代价”写得出来。
- 新方向记入存档，供后续章节参考。

## 6. 结局的结构

结局分三条轴，各自只依据已经提交的事实生成，不虚构没有发生的行动：

| 轴 | 内容 | 来源 |
|---|---|---|
| 世界 | 第 3 节选出的 0–2 个方向；队伍自愿收束且世界层没有足够事实时，世界轴为“未决”，用 D01 作为框架 | 发展方向、世界事实 |
| 玩家事业 | 队伍建立的事业、救下的地区、留下的名声（无名 / 地方传说 / 大陆传说），按实际证据定级 | 玩家事业线、地区阶段 |
| 角色尾声 | 每名角色的动机、承诺、重要人物、付出的代价与最后的选择 | 个人线、人物记忆 |

因此一支从没去过钟城、在灰港经营酒馆的队伍，世界轴可以是“未决”，事业轴和角色轴照样完整。下面的 7 段按三轴组织：

1. **门前**（可朗读）：终局地点此刻的景象，所有到场的人物以当前状态出现。不在门前时改为队伍收束之处的景象。
2. **第七声**：主方向的核心画面；若有副方向，写出两者如何交织。
3. **理由**：用叙述而不是列表，让玩家看到“是你们做的这些事让世界走到了这里”（至少 3 件）。
4. **每个角色的尾声**：一段，回应其动机、钩子和纪念物。
4a. **玩家事业的尾声**：每项事业一段，写它此刻的状态、留下的人和名声。
5. **人物的尾声**：每个态度 ≥ +2 或 ≤ −2 的 A/B 级人物一句话。
6. **势力的尾声**：每个关系 ≠ 0 的势力一句话。
7. **未竟之事**：仍未关闭的故事线，各一句话，作为下一章的种子。
