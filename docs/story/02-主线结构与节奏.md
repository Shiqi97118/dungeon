# 02｜主线结构与节奏

> 本文件规定故事怎样从开场走到终局：幕结构、节奏单位、硬性门槛、世界时钟和进度指标。凡是写着“规则”的条目都是确定性规则，将来由程序执行，不交给 AI 临场判断。

## 1. 用户提出的两条硬性要求

1. **最短完成路线中，每个角色都要做出超过 30 次选择。**
2. **最短完成路线能得到的结局，只能占游戏内容的 10% 以内。**

本文件的落实方式：

- 第 1 条 → 规则 R1：任何结局都要求每名在队角色至少 31 次有效选择。
- 第 2 条 → 规则 R5：20 个发展方向分为四个深度档。在最低选择数（31 次）时只开放第 0 档的 2 个方向（2/20 = 10%）；其余 18 个方向要求更多选择数和更多已完成内容。按内容量算，最短路线只会经历开场和至多 3 段支线，不到全部 32 段冒险（7 个地区各 1 段核心与 3 段支线，加上空名之城的 3 段外环与终局）的 10%。

## 2. 节奏单位

| 单位 | 定义 |
|---|---|
| 有效选择 | 某角色在自己的回合里执行了一个行动（点建议行动、写自由行动、休息、照料同伴、旅行出发都算）。以下不算：观望（结束回合不行动）、因昏迷或暂离被跳过、在代价/承压弹窗里做的选择。 |
| 轮 | 所有能行动的角色各行动一次。 |
| 场景 | 发生在同一地点、围绕同一件事的一组行动，通常 2–5 轮。 |
| 冒险 | 一段有开头、转折和结果的故事，分为“核心冒险”（每个地区 1 段）和“支线冒险”（每个地区 3 段）。 |
| 旅途 | 地区之间的移动，固定为 1 个场景（1–2 轮），途中可能有遭遇、同行者对话和势力事件。 |

## 3. 四幕结构（幕不按时间切换，按进度切换）

| 幕 | 名称 | 进入条件（规则） | 这一幕要让玩家感受到什么 | 典型内容 |
|---|---|---|---|---|
| 一 | 第六声 | 开局 | 世界很大、很乱，每个人都有自己的理由被卷进来 | 灰港开场、四条钩子、第一次选择方向、第一段冒险 |
| 二 | 诸国之弈 | 完成第一段核心冒险，或大势时钟 ≥ 4 | 各势力开始注意到这支队伍，选择开始有后果 | 2–3 个地区、势力使者登门、第一个重大真相 |
| 三 | 风暴前夕 | 真相层级 ≥ 3，或大势时钟 ≥ 8 | 世界在滑向某个方向，必须决定站在哪里 | 势力冲突爆发、关键人物的暗线揭开、空名之城的门可能打开 |
| 四 | 第七声 | 满足终局条件（第 6 节） | 所有铺垫在这里兑现 | 终局地点、最后一轮选择、结局 |

## 4. 核心规则

| 编号 | 规则 |
|---|---|
| R1 | 每名在队角色的有效选择都 ≥ 31 次之前，不会进入终局。 |
| R2 | 大势时钟 0–12：每 4 轮 +1；势力动向达到高阶、重大失败、公开引发恐慌时额外 +1。完成一段核心冒险并选择“稳住局势”的结果时 −1（每段核心冒险最多一次）。 |
| R3 | 大势时钟到 12 时：若已满足 R1，立刻进入第四幕；若尚未满足 R1，进入“全面危机”状态——世界事件每 2 轮恶化一次（见第 5 节第 12 格），直到满足 R1 后进入第四幕。 |
| R4 | 已满足 R1 后，全体玩家可以一致同意“收束故事”，进入第四幕。 |
| R5 | 进入第四幕时，只有满足深度要求的发展方向才能成为候选（见第 7 节和 `06-分支与结局走向.md`）。 |
| R6 | 第四幕中每名角色再行动一次（“最后的选择”），此轮对发展方向的推动加倍。之后生成结局。 |
| R7 | 真相第五层只能在空名之城确认；进入空名之城需要 3 枚钟心，或 2 枚钟心加上守钟人大钟主赛勒斯（或其继任者）引路。 |

## 5. 大势时钟：世界在变

时钟每升一格都会发生一件世界级事件。事件写成“默认版本”；如果相关势力已被玩家改变（结盟、削弱、首领被说服或失势），AI 改写为相应版本。

| 格 | 世界事件（默认版本） |
|---:|---|
| 0 | 第六声后的第九十天。人们还在为钟响争论。 |
| 1 | 灰港议会通过“回响物品登记令”，黑市价格翻倍。 |
| 2 | 卡尔维斯王都传出国王奥斯瓦尔德四世当众认不出摄政公主的消息。 |
| 3 | 白砾山脉的回声井失去控制，矿工们开始用亡者的声音说话。 |
| 4 | 铜脉商会宣布“回响通讯”试运营，第一批远距离对话成功。 |
| 5 | 烬原部族向王国边境进军，要求归还烬钟城圣地。 |
| 6 | 栖钟城一整条街区在一夜之间从所有人的记忆里消失。 |
| 7 | 守钟人在各地抓捕“知道太多的人”，并抹去他们的记忆。 |
| 8 | 沉默海上出现由回声凝成的幽灵船队，海路断绝。 |
| 9 | 遗忘病在三座城市同时暴发；空名者第一次用万人同声说话。 |
| 10 | 王国与烬原正式开战，或王国以“治愈”为名开始征用各地回声井（取决于势力状态）。 |
| 11 | 空名之城的雾墙开始后退，第七道门在远处显现。 |
| 12 | 第七声将要响起。进入第四幕；若尚未满足 R1，则进入“全面危机”：每 2 轮再发生一次恶化（一座城市失去名字、一位已遇到的 NPC 患上遗忘病、一条海路或道路断绝等，由 AI 依当前局势选择）。 |

## 6. 进度指标（存档中记录，供 AI 与程序共同读取）

| 指标 | 范围 | 如何增长 |
|---|---|---|
| 有效选择数 | 每名角色分别计数 | 见第 2 节 |
| 大势时钟 | 0–12 | 见 R2 |
| 真相层级 | 0–5 | 取得某层的任一可靠证据即视为“已知”，见 `03-地区与冒险.md` 冗余表 |
| 钟心 | 0–7 | 核心冒险的结果之一；也可以被抢走、交出或毁掉 |
| 已完成的核心冒险 | 0–7 | 冒险到达“结果”一节即完成，无论成败 |
| 已到访地区 | 1–8 | 首次进入该地区 |
| 势力关系 | 每个势力 −3…+3 | 见 `04-势力与动向.md` |
| 人物态度与状态 | 每个核心人物 −3…+3，加状态 | 见 `05-人物档案与关系网.md` |
| 故事线 | 最多 8 条未完成 | AI 开启和关闭，每条一句话 |
| 发展方向倾向分 | 20 个方向各自计分 | 见 `06-分支与结局走向.md` |

## 7. 深度档与最短路线

| 档 | 方向数 | 进入候选的最低条件（全部满足） |
|---|---:|---|
| 第 0 档 | 2 | 满足 R1（每人 ≥ 31 次有效选择） |
| 第 1 档 | 8 | 每人 ≥ 40 次；完成 ≥ 1 段核心冒险；真相层级 ≥ 2 |
| 第 2 档 | 6 | 每人 ≥ 50 次；完成 ≥ 2 段核心冒险；真相层级 ≥ 3；与该方向相关的至少 1 个势力关系达到 ±2 |
| 第 3 档 | 4 | 每人 ≥ 60 次；到达空名之城；真相层级 ≥ 4（第五层在城中确认） |

**最短完成路线**：开局后不完成任何核心冒险，满足 R1（31 次）后立即“收束故事”。此时只有第 0 档的“未竟之歌”和“大遗忘重演”两个方向可选，占 20 个方向的 10%；经历的内容只有开场和至多 3 段支线。

**深度与时钟的拉扯**：按时间推进，大势时钟约在第 48 轮到 12。想走到第 3 档（≥ 60 次），玩家必须通过完成核心冒险、稳住局势来拨慢时钟（R2），或在“全面危机”中坚持到条件满足。这是有意的取舍：越想看到宏大的结局，越要在世界崩坏之前做更多事。

**预计时长（待试玩校准）**：第 0 档约 31 轮；第 1 档约 40–50 轮；第 2 档约 50–60 轮；第 3 档约 60–80 轮。单人一轮约 1–2 分钟，四人一轮约 4–6 分钟。

## 8. 开场：第六声之后

**地点**：灰港，七灯酒馆。暴雨夜。

**可朗读**：

> 九十天前，伊瑟兰所有的钟在同一刻响了六下——王都的大钟、渔村的小钟、修道院里锈死了一百年的钟。然后，所有人都在等第七下。它没有来。
> 今夜的灰港下着暴雨。七灯酒馆里，七盏灯只亮了六盏。吟游诗人唱到一半忘了词，酒保擦着同一只杯子擦了很久。门被推开的时候，风把第六盏灯也吹得摇晃起来。

**开场时同时摆在桌上的四条钩子**（玩家可接任何一条，也可都不理，自己去做别的事）：

| 钩子 | 发起人 | 通向 |
|---|---|---|
| 商会重金招人，去白砾山脉找回失联的测绘队 | 卢多·费恩（铜脉商会代理人） | 白砾山脉核心冒险“第七道门的回声” |
| 一名浑身湿透的守钟人倒在酒馆门口，把一枚静音晶体塞给某个角色，只说“别让第七声响起” | 守钟人信使托马斯（随后被追兵带走或死于伤势，由玩家行动决定） | 守钟人线、沉默海、空名之城 |
| 王室告示：摄政公主悬赏能治愈“遗忘病”的人 | 告示与王室传令官 | 卡尔维斯王国核心冒险 |
| 某个角色的纪念物开始发热，指向一个他从未去过的地方 | 角色自己的钩子 | 该角色的个人线所连接的地区 |

**开场规则**：AI 必须在第一幕内为每名角色抛出至少一个与其纪念物、动机或队伍关系有关的钩子；第一幕结束前，每名角色至少与一位核心人物有过直接互动。

## 9. 故事线的生命周期

1. **开启**：AI 在叙述中引出一件悬而未决的事，同时把它写成一条故事线（一句话，最多 8 条）。
2. **推进**：玩家行动让故事线出现新进展时，AI 更新这一句话。
3. **关闭**：故事线得到结果（无论好坏）时关闭，并记录结果。关闭一条故事线可以推动发展方向。
4. **超限**：已有 8 条时，AI 不能开启新线，只能推进或关闭已有的；这防止故事散掉。

## 10. 节奏守则（给主持人）

- 每 3–4 轮至少有一件“世界在动”的事：势力动作、NPC 自主行动、时钟事件或旅途遭遇。
- 每段核心冒险至少给出一个没有正确答案的抉择。
- 连续 2 轮没有推进任何故事线时，AI 应主动引入一个推动事件（使者、追兵、消息、异象），而不是继续描写环境。
- 不用强制等待或重复内容凑数；选择数门槛靠真实的内容撑起来。
