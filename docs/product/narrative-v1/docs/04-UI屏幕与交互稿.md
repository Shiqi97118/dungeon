# 04｜成就图鉴、解锁弹窗、结局进度：UI 逐屏设计

## 设计语言

- 和伊瑟兰世界观一致：暗蓝黑、旧铜/羊皮纸、低饱和五分类色。数字、状态和操作可读性优先，不牺牲对比度换氛围。
- 屏幕目标：桌面和移动端优先单屏，不靠整页不断滚动。长文字使用页面内部独立滚动/翻页，保留当前阅读位置，新 AI 内容不抢页。可用方向键/上一页下一页。
- 界面克制：常驻入口不占剧情主视野；只在解锁后通过非阻断提示反馈。所有状态不仅靠颜色区分。

## 画面 A：主界面 / 标题页成就入口

- 在 `Title`/大厅顶部或功能入口新增 `成就`（奖杯图标 + `12/50`），不覆盖 `开始冒险/继续游戏/多人联机`。
- 用户触发进入成就图鉴全屏层；关闭恢复原焦点。中途游戏按暂停菜单打开，不修改游戏世界状态。
- 第一次进入提供一句说明：“记录那些被世界记住的事情。隐藏事迹将在亲历后显现。”无强制新手教程。

## 画面 B：成就图鉴（桌面）

```text
┌──────────────────────────────────────────────────────────────────┐
│ ← 返回    成就图鉴             已获得 12/50  ███░░ 24%            │
├───────────────┬──────────────────────────────────────────────────┤
│ 全部 50       │ [所有状态 ▼] [稀有度 ▼] [最近获得 ▼] [搜索]        │
│ 剧情 12       │ [图]第六声之后   [图]真相记录  [锁]???  [图]...    │
│ 人物 10       │ [图]初次承诺     [锁]未获得  [图]...               │
│ 探索 10       │ [图]探路者       [图]...                           │
│ 沙盒 8        │                                                  │
│ 传奇 10       │ 第 1 / 4 页                     ◀ 上页 下页 ▶     │
├───────────────┴──────────────────────────────────────────────────┤
│ 最近：第六声之后 · 由角色获得    [查看编年史]    [返回游戏]      │
└──────────────────────────────────────────────────────────────────┘
```

- 桌面总栏最小宽度 960px 时 5 列，较窄 3 列；分类栏固定宽 ~160px，网格区自适应。
- 每页 10～15 个；保留筛选状态、页号、列表焦点；支持鼠标滚轮在网格容器滚动，切页不是整个页面刷新。
- 无数据状态明确：“还没有解锁该分类的成就”；隐藏秘密成就不泄露详情。

## 画面 C：移动端图鉴

```text
┌──────────────────────────┐
│ ← 成就图鉴          12/50│
│ ▰▰▰▱▱ 24%               │
│ [全部][剧情][人物]→      │
│ [已获得▼] [排序▼]       │
│ [图] 成就    [锁] ???    │
│ [图] 成就    [图] 成就   │
│ [图] ...                │
│          ◀ 1/5 ▶        │
│ [返回游戏]              │
└──────────────────────────┘
```

- 竖屏 2 列，网格卡至少 44px 触摸目标，顶底安全区，状态栏不挡交互。
- 每页 8 个；使用内部容器和翻页，不强迫向下长滚动。筛选栏横向滚动，但可以键盘焦点触达。
- 文字“已获得/未获得/隐藏”必须清晰，秘密成就统一锁图且名称 `???`。

## 画面 D：单项详情抽屉 / 弹窗

- 标题、96px 图标、名称、稀有度、分类、简短故事性说明、可见条件、进度、来源局与解锁时间、`查看本局事迹`、可选设置称号。
- 未获得且秘密：统一灰锁图，`尚未发现`，无真实 icon/触发条件；未获得但公开：公开说明与允许的进度。
- 键盘：打开即聚焦标题或关闭按钮；Tab 限制在真正的 modal 内；ESC 关闭，关闭时焦点返回开启按钮。
- 移动端使用底部抽屉或全屏层，软键盘出现时不挡输入；长描述内部滚动，不影响游戏日志位置。

## 画面 E：解锁 Toast（非阻断）

```text
         ┌──────────────────────────────┐
         │ ✦ 成就解锁 · 稀有             │
         │ [图标]   不愿遗忘的人          │
         │ 你让一个重要名字重新被记起    │
         │                      [查看]   │
         └──────────────────────────────┘
```

- Toast 不自动导航/抢焦点。桌面右上，手机顶部 safe area 下，不遮剧情当前触点。
- 进入优先级：`玩家安全确认/QTE/骰子/分页阅读 > 解锁提示`；重要交互期间入队。
- 4–6 秒消失，用户操作时暂停；同批 4 项以上折叠；尊重 `mute` 与减少动画。
- 显示结果来自 `UnlockRecord(verified)`；离线待同步时显示“本地待确认”状态，不假装最终入账。

## 画面 F：结局页成就进度

```text
┌────────────────────────────────────────────────────────────────┐
│ 第七声之后 · 本局终章                                       │
│ ┌ 世界走向 ┐ ┌ 你的事业 ┐ ┌ 角色的后来 ┐                    │
│                                                                │
│   本局新解锁 4 项       本局达成 7 项       永久收藏 12/50    │
│   [史诗图]   [稀有图]   [普通图]   [普通图]                       │
│   永久进度 24% █████░░░░░                                       │
│   剧情 4/12 │ 人物 3/10 │ 探索 2/10 │ 沙盒 2/8 │ 传奇 1/10     │
│   本局传奇事迹：无冠的守护者 → 查看编年史                        │
│   [导出回忆]      [打开成就图鉴]       [重新冒险]                │
└────────────────────────────────────────────────────────────────┘
```

- 这只是**布局示意**，数字来自真实事件而非写死；三轴结局在上方，成就总结不得压过剧情尾声。
- 明确区分 `本局新获得`、`本局已达成`、`账号累计`；不把隐秘未获得的真实名称放在“尚未获得”区。
- 当本局成就为 0 时依然显示故事回顾，不能营造“玩家失败”或“没玩好”的羞辱语气。
- 可以复制/导出成就纪念卡和编年史文本，导出前先剔除敏感个人信息和私密文本。

## 状态矩阵（逐个要测试）

- 图鉴：加载中 / 空账号 / 部分解锁 / 50 项全得 / 无网络 / 同步中 / 权限失效。
- 成就卡：已获 / 未获公开 / 未获提示 / 未获秘密 / 本局刚获 / 已获再次达成。
- Toast：普通 / 稀有 / 史诗 / 传奇 / 同时大量解锁 / 正在 QTE / 正在阅读 / 音效关闭。
- 结局：单人 / 四人 / 新人中途加入 / 离线存档 / 动态传奇事迹有或无。
