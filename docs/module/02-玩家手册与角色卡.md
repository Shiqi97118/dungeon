# 02｜玩家手册与角色卡

> 本文件为玩家可见资料。不要在开局前阅读主持人文件。

## 你们要玩的故事

白砾矿场封闭多年。四天前，一支测绘队进入旧矿寻找一条失踪的地下水道，至今没有回来。昨夜矿井深处传出队长的声音，要求任何人都不要沿原路进入。你们受雇前往查明情况，并尽可能带回幸存者。

你们可以调查、谈判、潜行、战斗、合作或撤离。没有唯一正确的解法；主持人会根据你们实际采取的行动改变事件。你们不需要猜作者预设的答案。

## 轻量规则

当行动有风险且失败会带来有意义的代价时，掷 **2d6 + 一项属性**：

- **10+：** 成功，得到想要的结果。
- **7–9：** 成功但要付出代价，或在两个结果中选择一个。
- **6 以下：** 事情变复杂；主持人推进威胁、制造代价或给对手行动机会，但故事继续。

属性：**强韧、灵巧、洞察、交涉**。属性通常为 -1、0、+1、+2。若有合适的专长，掷骰 +1。明显有利或不利的情形，再额外 +1 或 -1（最多只调整一次）。总加值最高 +3、最低 -2。

每个角色有 **3 格承压**。受伤、恐惧、迷失或过度用力可能填一格。满 3 格后，下一次承压会让角色暂时退出当前危险场面，之后与主持人协商留下何种后果。短暂休息并互相照料可清除 1 格；本章结束时清空承压，除非玩家希望保留故事后果。

**优势点：** 每人开场 1 点。花费 1 点可把一次 7–9 的代价降为轻微代价，或在符合角色动机的行动中重掷一颗骰子。通过帮助他人、承担个人动机带来的麻烦、或做出保护队伍的牺牲可获得优势点；每人最多 2 点。

## 规则原则

- 没有风险的常规行动不掷骰，直接成功。
- 掷骰前，主持人应说明失败可能带来什么类型的后果。
- 关键线索不因失败而消失；失败改变的是取得线索的代价、时间或风险。
- 你可以拒绝角色死亡或永久创伤；主持人会提供更合适的后果选项。
- 你可以随时要求暂停、略过、淡化或调整场景内容。
