# 《回声井：第七道门》可运行模组包

**类型：** 奇幻地下城 / 探索 / 阵营抉择  
**人数：** 1–6 名玩家 + AI 主持人  
**时长：** 2–4 小时  
**规则：** 本包内含原创轻量规则，无需其他规则书  
**视觉：** 关键场景插图辅助叙事，无需动画或地图战斗系统

## 文件顺序

1. `01-主持人速查与开团流程.md`：开团前读；游玩时作为主索引。
2. `02-玩家手册与角色卡.md`：可直接发给玩家，不含剧透。
3. `03-模组正文-回声井.md`：主持人专用，含真相、场景、线索、分支与结局。
4. `04-NPC与威胁档案.md`：扮演提示、秘密、能力与行动原则。
5. `05-角色创建与随机生成器.md`：快速建卡、完整模板、随机表和预制角色。
6. `06-AI主持人运行规范与状态存档.md`：系统提示词、状态字段、回合格式、摘要与续团模板。
7. `07-插图与展示材料清单.md`：插图提示词、玩家手卡和安全设置。

## 运行建议

- 首次使用时先读 01、03、06；玩家只看 02、05 中的玩家区。
- 让 AI 主持人把 06 的“固定主持规则”和 03 的“主持人秘闻”作为私有上下文；02 是公开上下文。
- 角色直接选 05 的预制角色即可开场。自由创建只需 5–10 分钟。
- 按推荐流程跑 5–7 个场景节点；不要要求玩家访问全部地点。
- 章节结果和续章钩子记录在 06 的状态存档中。

## 内容提示

包含地下空间、失踪、受困、非致命心理压力与道德抉择。开始前询问玩家希望避开的内容；可将“记忆被改变”“角色被困”淡化或排除。所有角色死亡或永久创伤均须由玩家明确接受，不由一次掷骰强加。

## 模组设计原则

本包把场景、线索、NPC、威胁与结局分开，给玩家多条调查路径，并允许地点被跳过；关键线索可从多个渠道取得，避免一次失败令剧情停摆。Dicecho 用户提供的目标合辑目前显示 0 个藏品，因此结构参考了 Dicecho 上《Blackwater Creek》的公开介绍，而非复刻任何具体故事或文本。
