# 04｜NPC 与威胁档案

## 宁芮｜测绘队长

- **表面：** 精疲力竭、谨慎、手握晶核；宁愿相信井中妹妹的声音是真的。
- **真正目标：** 让妹妹“回来”，哪怕必须交出自己的记忆。
- **知道：** 核心能播放记忆片段；不知道它是否真有自主意识。
- **声音/动作：** 说话前会先听一秒；回答问题时偶尔重复对方最后一个词。
- **可被说服：** 玩家能证明妹妹的声音来自她从未告诉过别人的记忆之外的拼接；或提出能够保留片段但停止吞噬的方案。
- **底线：** 不主动牺牲测绘队同伴；若玩家攻击她，她会优先逃向控制台。
- **能力：** 体力 2，防护 0；熟悉矿区。她不是首领，优先谈判或逃跑。

## 乔安｜幸存测绘员

- **表面：** 警惕、嘴硬、保护队友。
- **目标：** 救回宁芮和失踪伙伴，然后离开矿区。
- **秘密：** 她已忘记自己的姓氏；她留给自己一封信，提醒她“别相信熟悉的声音”。
- **能提供：** 核心路线、拆除传声骨架的方法、测绘队分裂经过。
- **关系：** 曾把宁芮视作导师；担心宁芮听见妹妹的声音后会不顾他人。
- **能力：** 体力 1，防护 0；可协助一个非战斗检定，不替玩家行动。

## 伊芙琳｜守井者

- **表面：** 平静、克制、疲惫；把名字写在手臂上，防止遗忘。
- **目标：** 阻止井再吞噬任何人的记忆。
- **秘密：** 她曾经成功封过一次井，但也因此忘记了自己的搭档。
- **误解：** 认为修复几乎不可能，但若获得七音证据和自愿记忆承诺，会考虑参与。
- **扮演指引：** 只讲自己亲历或证据支持的事实；不掌握完整古代历史。
- **能力：** 体力 2，防护 1；擅长机关和矿道，避免将其写成强制盟友或敌人。

## 陆铎｜矿业公会代理人

- **表面：** 礼貌、务实、愿意付钱；装备齐全，带一名向导。
- **目标：** 安全带回晶核，证明公会能管好它。
- **秘密：** 他隐瞒了公会已有两名矿工因失忆被送回地面。
- **可谈判：** 公开研究结果、允许幸存者先撤离、让玩家保管晶核、签下监督承诺。
- **扮演指引：** 他相信自己能控制风险；若证据显示失控，愿意撤退，不会为反派而反派。
- **能力：** 体力 2，防护 1；手枪仅在受到威胁时使用，伤害后果由玩家安全边界决定。

## 回声仿兽｜环境威胁

- **呈现：** 由洞穴蝙蝠、矿尘和回声构成的模糊兽影；只会重复听过的声音。
- **意图：** 靠近声音源并吸收声音，不以杀死角色为目标。
- **规则：** 危险 2；每次危机需要队伍填满 3 格进度（击退、安抚、诱离、封住通风道都有效）。每次失手造成承压、失去小物件或压力 +1，玩家从中选择。
- **弱点：** 稳定节奏、镜面反射、低频振动、保持静默。
- **退场：** 完成目标、失去声音源、受伤两次或玩家创造足够有利环境。

## 回声井本身｜非人格化威胁

- **意图：** 修复存储装置；读取可接近的记忆并模仿声音。
- **不做：** 不说谎以恶意欺骗，不全知，不以角色最私密创伤作为自动惩罚。
- **表达方式：** 复述熟悉声音、提前播放片段、让空间出现短暂错位。
- **裁定：** 井的声音是数据，不等于被保存者的完整灵魂；但玩家可以选择相信其意义。

## NPC 扮演通用规则

每个 NPC 只主动追求其目标、使用自己知道的信息、对可见证据作出反应。玩家改变处境后，NPC 也要改变立场。不要让 NPC 抢走玩家的解决问题机会。
