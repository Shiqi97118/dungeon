## 一句话

第六声之后，全大陆都在等第七声。一支小队被卷进商会、王室、教团、学院、部族与一个由四百年被遗忘之名聚成的意识之间的风暴——他们做的每一件事，都会让世界向二十个方向中的某一个倾斜。

## 用户的要求与落实位置

| 要求 | 落实位置 |
|---|---|
| 恢弘的原创奇幻世界，不局限于矿洞 | `01`；原矿洞成为白砾山脉的一段核心冒险（`03` 第 5 节） |
| 玩家做任何事都合理 | `07` 第 3 节；`05` 第 9 节（路人生成） |
| 更多故事分支，结局不提前固定 | `06`：20 个方向 + 加权随机候选 + AI 裁决 + 可提出新方向 |
| AI 在合适的时间给出最让人信服的结局 | `02` R1–R6；`06` 第 3、6 节 |
| 最短路线每人 > 30 次选择 | `02` R1（≥ 31 次） |
| 最短路线可达结局 ≤ 10% | `02` 第 7 节；`06` 第 7 节（2/20，内容约 3/32） |
| 西方大陆风格的人名地名 | `01` 第 2 节；`05` 第 11 节（旧名对照） |
| NPC 量级、性格、特质、关系、明线暗线，一举一动影响走向 | `05` 全文；`04` 第 3–6 节 |
| 调高 AI 次数与配置 | `08` 第 2、3 节（建议值，待确认后实施） |
| 旧存档可不兼容 | `08` 第 4 节 |
