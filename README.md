# 回声井：第七道门 · 网页跑团

基于 `docs/module/` 中的原创模组包制作的单页网页跑团游戏。浏览器打开即可游玩，无需后端。

## 玩法概览

- **开团流程**：内容边界与淡化设置 → 选择 1–4 名预制或随机角色 → 填写入团理由与队伍关系 → 接受委托。
- **2d6 轻量规则**：检定前展示属性、专长、情境加值与失败风险；10+ / 7–9 / 6- 三档结果；7–9 由玩家选择代价，可花优势点减轻代价或重掷一颗骰。
- **回声压力时钟 0–6**：深入、拖延、失败会让井“清醒”，触发模组里的世界反应（影子副本、遗忘对话、核心开门），到 6 强制进入终局。
- **7 个地点 + 开场**，访问顺序自由；关键线索有多条冗余来源，失败不会锁死剧情。
- **NPC**：宁芮、乔安、伊芙琳、陆铎各有目标与态度变化；陆铎会带着破岩钻中途追上来。
- **互动谜题**：在水闸礼堂和井底按残谱敲响六口钟，第七音必须由“静默”完成。
- **5 种结局 + 自创方案**：封存、修复（需要一段自愿交出的记忆）、摧毁、交付、撤离；结局后为每位角色记录“带走了什么”，并导出符合模组 06 模板的章节存档。
- **自由行动**：输入框可以写下任何行动。离线时由规则裁定（选属性掷骰，按结果推进线索或付出代价）；配置 AI 主持人后，由大模型依照模组 06 的主持规范即兴叙述，并以受限的结构化指令修改游戏状态。

## AI 主持人（可选）

标题页或游戏顶栏点击“AI 主持人”，填写任意兼容 OpenAI Chat Completions 的接口（预设 DeepSeek / OpenAI / 通义千问 / Moonshot）。密钥只保存在本机浏览器的 localStorage，并由浏览器直接请求所选服务商。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm test         # 引擎测试：400 局随机游玩 + 各结局路线
npm run build    # 产物在 dist/，可部署到任意静态托管
```

目录结构：

- `src/game/`：规则引擎、场景数据、线索、结局与 AI 主持人协议
- `src/ui/`：界面组件（标题、建卡、游戏主界面、掷骰、七钟谜题、结局）
- `src/audio/`：Web Audio 合成的雨声、矿洞环境音、钟声、骰子音效
- `public/art/`：按模组 07 插图提示词生成的场景插图
