## 2. 桌面 / 手机布局规格

### 2.1 桌面（≥ 1024px）

```
┌──────────────────────────────┬───────────────┐
│ 阅读工具条（字号/专注/朗读/未读）            │ 当前行动角色  │
│ ──────────────────────────── │ 符印+轮廓+状态│
│ 叙事 Log（独立滚动，min-width 55%）         │ 压力钟 0–6    │
│                              │ ─────────────│
│                              │ 5 页签        │
│ ──────────────────────────── │               │
│ 行动输入 / 预设行动 / 掷骰面板                │               │
└──────────────────────────────┴───────────────┘
```

- 叙事容器自身滚动，页面不整体滚动；新增消息不触发 `window.scrollTo`。
- 右栏宽度固定（建议 280–320px），窄屏时先折叠页签再折叠整栏。

### 2.2 手机（< 768px）

- 单栏：`[迷你行动者条] → [叙事 Log，flex:1] → [固定底部行动输入]`。
- 抽屉从底部升起，最大高度 60vh，含完整 `Sidebar` 内容；抽屉打开时行动输入仍可见（抽屉止于输入区上沿）。
- 键盘弹出：监听 `window.visualViewport.resize`，把底部输入的 `bottom` 与叙事区 `padding-bottom` 同步调整；失焦复原。
- 字号在手机上允许 16–26px 但**叙事区不得横向滚动**，长段落靠换行；`scene-break`（`Log.tsx:68-75`）标题可缩小但不换行截断。
- 朗读 / 字号 / 专注收进「阅读」菜单，工具条只保留「从未读处继续」这一个情境按钮。

### 2.3 断点与降级

| 宽度 | 行为 |
|---|---|
| ≥1280 | 三区完整 |
| 1024–1279 | 右栏收窄，页签横向滚动 |
| 768–1023 | 右栏变抽屉，迷你行动者条常驻 |
| <768 | 单栏 + 底部输入 + 抽屉（第 2.2 节） |
| 无 `speechSynthesis` | 隐藏朗读 / 停止按钮（`Log.tsx:16` 已有 `speechAvailable` 判断，沿用） |

## 4. 未读定位 / 字号 / 朗读：具体行为与异常

以下逐条给出**目标行为**，并标注与 `Log.tsx` 现状的差异；均为可执行验收项（`协作规范.md:27`）。

### 4.1 回看历史时新增消息不改变位置

- 目标：玩家滚到历史任意位置，期间到达新叙事 / `thinking` 变化 / 掷骰结果，滚动位置**保持不变**；只在工具条出现「从未读处继续 ↓」。
- 现状：`Log.tsx:33-37` 的 effect 只更新 `seen`/`anchor`，不主动滚动，方向正确；但 `:50` `firstNew = seen.current` 在渲染期取值，重渲染可能让新条目 `isNew` 重算并重放 `:51` 的 220ms 动画，造成视觉跳动。
- 改动：把 `firstNew` 固定为「本次新增区间的起点 id」（与 `anchor` 同源），新增条目动画只播放一次；`thinking` 占位（`:54-56`）不参与 `anchor` 计算。

### 4.2 继续阅读定位第一条未读

- 目标：点击「从未读处继续」精确停在第一条新消息顶部（留 12px 余量），清除 `unread` 与 `anchor`。
- 现状：`Log.tsx:25-31` 用 `el.scrollTop += entry.getBoundingClientRect().top - el.getBoundingClientRect().top - 12` 相对叠加，在长段落折叠展开、字号变化、背景图加载后会偏移。
- 改动：改为绝对定位 `el.scrollTop = entry.offsetTop - el.offsetTop - 12`（或 `entry.scrollIntoView({block:'start'})` 且限定滚动容器），并在「字号变更 / 折叠展开」后重算 `anchor` 的偏移缓存。

### 4.3 长段落

- 单条叙事超过阈值（建议 300 字，`ai.ts:631` 已把每段截到 600 字）时折叠为前 120 字 + 「展开全文」；折叠状态按 `entry.id` 保存，不因新增消息重置。
- `forgotten` 条目（`Log.tsx:66`、`fx.ts:71-75`）保留视觉标记（现有 `.forgotten` + title），但**不参与朗读**且不被「未读」计入。

### 4.4 AI 连续行动

- `thinking` 占位与连续多条 `ai` 日志到达时，`anchor` 只取第一条新消息，不逐条弹按钮；`stagger` 动画延迟设上限（建议最多 6 条、单条 ≤ 220ms），避免长串叙事延迟数秒才可见。
- 新增消息到达时不自动滚动、不自动开始朗读。

### 4.5 加载存档 / 切换会话

- `seen` 初始化为 `state.log.at(-1)?.id`（`Log.tsx:9` 已如此），`anchor=null`、`unread=false`；载入旧存档不出现「从未读处继续」。
- 字号从 localStorage 恢复（新增）；`forgotten` 条目按存档标记还原。

### 4.6 语音朗读与停止

| 场景 | 目标行为 |
|---|---|
| 开始朗读 | 取最近 6 条 `read/narr/npc/ai` 且 `!forgotten`，`lang='zh-CN'`；**逐条高亮当前句**，提供「暂停 / 继续 / 停止」三态（现状只有 speak + cancel） |
| 停止 | 按钮、离开界面（`Log.tsx:32` 已有）、切换页签 / 抽屉、开始新朗读前，均调用 `speechSynthesis.cancel()` 并清除高亮 |
| 朗读中新增叙事 | 不自动追加、不打断；显示「有新内容，朗读完可继续」提示，由玩家手动触发 |
| 不可用 | `speechAvailable === false` 时隐藏朗读与停止按钮（`Log.tsx:16,45` 已有判断） |
| 移动端 | 朗读控件在「阅读」菜单内，不占首屏；锁屏 / 切后台时 cancel |

### 4.7 字号

- 范围 16–26px，步进 1（现状 `Log.tsx:12,43` 为 `useState(18)` + range），**持久化到 localStorage**，作用于 `.log` 与 `.scene-break`，不影响工具条与行动输入。
- 字号变更后：重算未读锚点偏移（4.2）、保持当前滚动位置不跳变、不重放新消息动画。
- 手机端叙事区不出现横向滚动条。
