# 05｜角色创建与随机生成器

## 快速创建（约 3 分钟）

1. 选一个预制角色，或在下方随机表各掷一次。
2. 分配属性：四项数值为 **+2、+1、0、-1**，各用一次。
3. 从专长表选两项；挑两件装备。
4. 补上来此理由和一条队伍关系。承压 0/3，优势点 1。

## 属性说明

- **强韧：** 扛住伤害、负重、攀爬、抵抗极端环境。
- **灵巧：** 潜行、躲避、精细操作、快速行动。
- **洞察：** 调查、追踪、辨认谎言、理解古代装置。
- **交涉：** 安抚、说服、欺瞒、建立信任或施压。

## 装备（选 2）

绳索与钩爪、可靠灯具、急救包、撬棍、测绘工具、旧地图、折叠镜、录音筒、简易乐器、信号弹、工会通行证、防水斗篷、两人份干粮、可拆卸水闸扳手、其他合理小物。

每件装备解决一个具体问题或提供一次优势；装备不是无限次的万能解法。任何角色都可携带一件不构成强力武器的个人纪念物。

## 随机背景表

每项掷 d6，也可自由选择。

### 职业 / 来历

1 矿场工匠；2 城镇医者；3 流浪向导；4 学院研究员；5 退役护卫；6 地方信使。

### 个人动机

1 证明自己没有抛下旧伙伴；2 找回家族遗物；3 还清一笔人情债；4 调查一段不合常理的记忆；5 保护委托人雇来的某个人；6 需要钱离开故乡。

### 角色矛盾

1 想被信任却习惯隐瞒；2 崇尚秩序但不服从权威；3 勇敢行动却害怕被遗忘；4 看重承诺却曾违约；5 追求真相却不愿听答案；6 擅长独处但希望有人留下。

### 纪念物

1 一封未寄出的信；2 缺了一齿的铜钥匙；3 亲友留下的布片；4 一枚无主工牌；5 写有陌生名字的石片；6 失灵但仍上弦的怀表。

### 队伍关系（任选）

- 我曾把命交给 ____，但没告诉其他人原因。
- ____ 知道我在寻找什么，我希望他/她别说出来。
- 我欠 ____ 一个解释；我一直在拖延。
- ____ 和我来自相同的地方，但记得的版本不同。
- 我不完全信任 ____，但此刻只相信他/她。
- 我曾经救过 ____；如今角色互换了。

## 预制角色

属性顺序均为强韧 / 灵巧 / 洞察 / 交涉。

### 1. 赫岚，前矿工

属性 +2 / 0 / +1 / -1。专长：矿道熟手、护卫。装备：绳索与钩爪、撬棍。动机：证明旧事故不是自己造成的。关系钩子：曾在一次塌方中丢下同伴；可与任何角色建立旧债。

### 2. 芙禾，巡回医者

属性 0 / +1 / +2 / -1。专长：急救者、记述者。装备：急救包、旧地图。动机：找到一位失踪病患。关系钩子：曾救过乔安，但她不记得芙禾。

### 3. 祁岚，钟匠学徒

属性 -1 / +1 / +2 / 0。专长：机械匠、演奏者。装备：测绘工具、简易乐器。动机：听懂一段从童年起反复出现的旋律。关系钩子：相信伊芙琳说的部分真相。

### 4. 洛岑，边境向导

属性 +1 / +2 / 0 / -1。专长：野外人、侦察员。装备：可靠灯具、防水斗篷。动机：拿钱带家人离开矿区。关系钩子：受陆铎雇佣过，但不想再次替公会冒险。

### 5. 梅迦，流动说书人

属性 -1 / +1 / 0 / +2。专长：谈判人、演奏者。装备：录音筒、折叠镜。动机：寻找一段被自己遗忘的故事。关系钩子：曾把某角色的秘密写进故事，尚未承认。

### 6. 达薇，遗迹学者

属性 0 / -1 / +2 / +1。专长：旧语学者、记述者。装备：旧地图、测绘工具。动机：让古代记忆库不落入公会手中。关系钩子：和伊芙琳的师父有过书信往来。

预制角色的关系钩子供玩家选择或修改，不应强迫某个既定角色关系。
