## 一句话

第六声之后，全大陆都在等第七声。一支小队被卷进商会、王室、教团、学院、部族与一个由四百年被遗忘之名聚成的意识之间的风暴——他们做的每一件事，都会让世界向二十个方向中的某一个倾斜。

## 用户的要求与落实位置

| 要求 | 落实位置 |
|---|---|
| 恢弘的原创奇幻世界，不局限于矿洞 | `01`；原矿洞成为白砾山脉的一段核心冒险（`03` 第 5 节） |
| 玩家做任何事都合理 | `07` 第 3 节；`05` 第 9 节（路人生成） |
| 更多故事分支，结局不提前固定 | `06`：20 个方向 + 加权随机候选 + AI 裁决 + 可提出新方向 |
| AI 在合适的时间给出最让人信服的结局 | `02` R1–R6；`06` 第 3、6 节 |
| 最短路线每人 > 30 次选择 | `02` R1（每席位 ≥ 31 次；中途加入、换角色、防刷见 R1a–R1c 与第 2 节） |
| 最短路线可达结局 ≤ 10% | `02` 第 7 节；`06` 第 7 节（至多 2/20，内容约 3/32） |
| 西方大陆风格的人名地名 | `01` 第 2 节；`05` 第 11 节（旧名对照） |
| NPC 量级、性格、特质、关系、明线暗线，一举一动影响走向 | `05` 全文；`04` 第 3–6 节 |
| 调高 AI 次数与配置 | `08` 第 2、3 节；每天最高 30 元的费用上限见 `12` 第 9 节 |
| 开工前把方案定清楚，减少返工 | `12`、`13`、`docs/协作看板.md` |
| 旧存档可不兼容 | `08` 第 4 节 |
| 不做“选择模拟器”：大量对话、旁白、承上启下与环境描写，模糊触发，一局内过渡文本不重复 | `09`；`text/`。BRG 过渡与剧情类一局只用一次；ENV、RST、TRV 冷却 20 轮后可复用（用户 2026-11-11 同意按设计包调整，`09` 第 3.4 节） |
| 大量插图配合文本、随剧情同步推进 | `10`；`public/art/story/`（12 张样张，已确认为风格基准） |
| 不要一句话就跳转，情节和内容更丰富 | `09` 第 3.3a 节（每屏下限、换场景三段式、不自动跳转）；`text/00` 全部过渡类条目扩写为两段 |
| 史诗主线 + 自由沙盒，世界与玩家事业独立发展又互相影响 | `02` R2–R4、第 9、11、12 节（事件推进的时钟、四层故事线、地区按势力前提收束、玩家事业）；`04` 第 8 节；`06` 第 6 节（结局三轴） |
| 人物记得发生过什么、只知道该知道的事 | `05` 第 2 节（近期印象、刻骨记忆、信念、知情）；`07` 第 4 节 |
| 预写剧情不得写出未发生的事 | `09` 第 2.1 节（可触发 / 禁止 / 需知 / 后置 / 交互，读写边界，结果类与抉择类节拍规则）；`07` 第 1 节（先有事件再有叙述）；各地区接口表 |

## 已确认（用户 2026-11-11）

1. AI 上限按 `08` 第 2 节的建议值提高（在开发阶段与新剧情一起实施，上线前核算费用）。
2. 结局生成单独使用更强的模型（`08` 第 3 节）。
3. 人物、暗线与 20 个方向由主持方自行决定：保持本框架，补齐了大钟主赛勒斯的台词。

4. `public/art/story/` 的 12 张样张作为风格基准；文风可以，但内容要更丰富、不要一句话就跳转。
5. 产品方向为“史诗主线 + 自由沙盒”；成就、图鉴与叙事微交互作为后续单独任务（`08` 第 5 节）。
